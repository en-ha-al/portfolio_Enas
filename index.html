بناء واجهات برمجية تجمع بين رصانة الهندسة وسلاسة التصميم

الربط بين الفكر التصميمي لتجربة المستخدم (UI/UX) والتطوير البرمجي المنظم وقابل للتوسع.

أنا خريجة في هندسة وتقنية البرمجيات، أمتلك شغفاً كبيراً بتطوير الواجهات الأمامية للويب وبناء الحلول الرقمية المتكاملة. منحني مساري الأكاديمي أساساً متيناً في معمارية البرمجيات، وتصميم وتوصيف قواعد البيانات، وإدارة دورة حياة المشروع البرمجي.

من خلال مشروعي التخرج 'يقين' وتصميمي لواجهات نظام شركة الشحن 'بريمولا'، اكتسبت خبرة تطبيقية في تحويل متطلبات الأنظمة إلى واجهات سلسة وسريعة الاستجابة. يمثل هذا الموقع سيرتي الذاتية التفاعلية المعتمدة.

دراسات الحالة والمشاريع

المشاريع المنفذة ودراسات الحالة

استعراض تفصيلي لأهم المشاريع الهندسية والتطبيقية بأسلوب دراسة الحالة.

مشروع التخرج المعتمد 2026 • ربيع 2026

يقين (Yaqeen) — منصة ويب ذكية لاكتشاف تزييف الوجوه بالذكاء الاصطناعي

المشكلة والتحدي

أدى الانتشار الهائل لتقنيات الذكاء الاصطناعي التوليدي والتزييف العميق (Deepfakes) إلى تهديد مصداقية الأدلة الرقمية وصعوبة التمييز بالعين المجردة. كان التحدي بناء منصة ويب متكاملة تجمع بين فحص الوجوه والتحليل الجنائي السريع.

الحل الهندسي المنفذ

نظام ويب ذكي يعتمد على معمارية هجينة تجمع بين نماذج التعلم العميق (EfficientNet-B3 مع شبكة الكبسولات CapsuleNet) وأدوات التحليل الجنائي الرقمي (تحليل مستوى الخطأ ELA والبيانات الوصفية EXIF) مع خرائط حرارية تفسيرية (Explainable AI).

دوري المحدد في المشروع:

  • تطوير الواجهات الأمامية للويب ولوحة التحكم الإدارية بالكامل باستخدام Vue 3 و TypeScript و Vite.
  • تصميم وتطوير مسارات تفاعل المستخدم لرفع الصور، ومحاذاة الوجوه المستخلصة، وعرض تقارير الفحص والنتائج الجنائية.
  • ربط وتكامل الواجهة الأمامية مع واجهة برمجة التطبيقات (Flask API) وإدارة تدفق البيانات مع Microsoft SQL Server.
التقنيات المستخدمة:
Vue 3 TypeScript Vite Python & Flask API MS SQL Server ELA Forensics & Grad-CAM

نظام شركة بريمولا (Primula) — تصميم واجهات وتجربة مستخدم لنظام إدارة الشحن والطلبيات

فتح نموذج Figma التفاعلي

المشكلة وسياق العمل

شركة بريمولا هي شركة شحن واستيراد طلبيات لزبائنها من المواقع العالمية. واجهت الشركة تحديات تشغيلية كبيرة في فترات الذروة بسبب الأنظمة اليدوية المتفرقة، مما أدى إلى صعوبة تتبع الشحنات وبطء معالجة الطلبات وضعف التواصل بين الأقسام.

الحل التصميمي وتجربة المستخدم في Figma

تصميم واجهات وتجربة استخدام متكاملة في Figma لنظام يربط العملاء والموظفين والمندوبين والإدارة. شمل التصميم شاشات تفاعلية لإدارة الطلبيات، ومتابعة الشحنات، وإصدار الفواتير، ونماذج الهاتف المحمول.

دوري في المشروع والأمانة المهنية:

  • المسؤولة عن تحليل وتصميم واجهات وتجربة المستخدم (UI/UX Design) بالكامل باستخدام Figma وبناء النماذج التفاعلية للشاشات.
  • تحليل وتوصيف حالات الاستخدام (Use Cases) وتصميم تدفق العمليات من تسجيل الشحنة وحتى التسليم للعميل.
توضيح للأمانة المهنية والعلمية: اقتصر دوري في هذا المشروع على دراسة وتحليل النظام وتصميم واجهات وتجربة المستخدم (UI/UX) باستخدام Figma. تولى فريق الطلاب الآخرين برمجة النظام، وتم اعتماد النظام رسمياً واستخدامه فعلياً من قبل شركة بريمولا.

البحث والتحليل
